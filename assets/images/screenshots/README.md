Put historical screenshot images here. Reference them from each OS record's
`screenshots` array in js/data.js, e.g.:

screenshots: [
  { file: "win95-desktop.jpg", caption: "Windows 95 desktop and taskbar", source: "https://en.wikipedia.org/wiki/Windows_95" }
]

The "file" value must match a filename in this folder exactly.
If a listed file is missing, that screenshot tile just hides itself — nothing breaks.
