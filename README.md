# 🖥️ OS Archive — The Digital Museum of Operating Systems

**OS Archive** is an interactive, web-based digital museum dedicated to preserving and exploring the history, architecture, and visual evolution of operating systems. Designed with a dark retro-computing aesthetic—blending CRT scanline nostalgia, terminal typography, and modern glassmorphism—it provides a comprehensive journey from early command-line interfaces to modern graphical desktop and mobile operating systems.

---

## ✨ Key Features

### 📜 Interactive Chronological Timeline

* Explore major milestones in computing history from the 1970s to present day.
* Interactive timeline entries with detailed modal inspection panels containing release dates, original developers, kernel architecture, UI overviews, historical impact, and trivia.

### 🖼️ OS Gallery & Visual Previews

* Recreated UI visual previews and vector-accurate logo assets for major releases.
* Granular filtering options by **Era**, **Developer**, **Platform Type** (Desktop, Mobile, Embedded), and **System Family**.
* Smooth transitions and glassmorphism hover animations.

### ⚖️ Side-by-Side Comparison Engine

* Compare any two operating systems side by side across key technical metrics:
* Release year & original developer
* Kernel architecture & underlying foundation
* Interface paradigm & target devices
* Customization, ecosystem, and historical significance



### 🌳 Visual Family Tree & Genealogy

* An interactive dependency tree mapping the branches of computing evolution:
* **UNIX & BSD Lineage**
* **DOS to Windows 9x & Windows NT Evolution** (including famous codenames like *Chicago*, *Memphis*, *Whistler*, *Longhorn*, *Blackcomb*, and *Threshold*)
* **Classic Macintosh to OS X / macOS Modern Stack**
* **Linux Kernel Evolution & Distribution Branches**
* **Mobile Paradigms** (Android, iOS, Windows Phone)



### 💻 Interactive Terminal Mode

* Integrated CLI simulation supporting safe interactive commands:
* `help` — List available shell commands
* `list [category]` — Query specific systems (e.g., `list macos`, `list windows`)
* `compare [os1] [os2]` — Direct terminal comparison lookup
* `random` — Quick fact generator
* `history` — Shell command log



### 🎮 "Guess the OS" Trivia Quiz

* Built-in interactive quiz testing knowledge of historic UI elements, screenshots, and clue prompts.
* Features a real-time score tracker, progress bar, instant feedback, and end-of-game performance summaries.

## 🏛️ Comprehensive Historical Coverage

* **Windows Family:** MS-DOS, Windows 1.0/2.0/3.1, Windows 95 (*Chicago*), Windows 98 (*Memphis*), Windows 2000, Windows NT line, Windows XP (*Whistler*), Windows Vista (*Longhorn*), Windows 7 (*Vienna*), Windows 8/8.1, Windows 10 (*Threshold*), Windows 11, and Windows Phone / 10 Mobile.
* **Apple Lineage:** System 1 through System 7, Mac OS 8/9, OS X Big Cats (*Cheetah* through *Snow Leopard*), OS X California Landmarks (*Mavericks* through *Catalina*), and Apple Silicon macOS (*Big Sur* through *Sequoia*).
* **Linux Milestones:** Kernel 0.01 initial drop, 1.0.0, 2.6 preemption milestones, 6.x LTS releases, and distribution foundations.
* **UNIX & Mobile:** Bell Labs Research UNIX, BSD lineages, Android milestones, and iOS origins.

## 🚀 Getting Started

Since **OS Archive** is built as a single-page standalone web application, running it locally is seamless:

1. **Clone the repository:**
```bash
git clone https://github.com/your-username/os-archive.git

```


2. **Navigate to the directory:**
```bash
cd os-archive

```


3. **Open in browser:**
Double-click `index.html` or serve it via any static server (e.g., Live Server extension in VS Code, Python `http.server`, or GitHub Pages).
